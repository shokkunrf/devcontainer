# Gemini CLI

Installs [@google/gemini-cli](https://www.npmjs.com/package/@google/gemini-cli) tool.

## Usage

```json
{
    "features": {
        "ghcr.io/shokkunrf/devcontainer-features/gemini-cli:1": {}
    }
}
```

## Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `version` | string | `latest` | Version to install |

# Dev Container CLI

Installs [@devcontainers/cli](https://www.npmjs.com/package/@devcontainers/cli) tool.

## Usage

```json
{
    "features": {
        "ghcr.io/shokkunrf/devcontainer-features/devcontainer-cli:1": {}
    }
}
```

## Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `version` | string | `latest` | Version to install |

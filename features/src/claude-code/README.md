# Claude Code

Installs [@anthropic-ai/claude-code](https://www.npmjs.com/package/@anthropic-ai/claude-code) CLI tool.

See also: [Official devcontainer feature](https://github.com/anthropics/devcontainer-features)

## Usage

```json
{
    "features": {
        "ghcr.io/shokkunrf/devcontainer-features/claude-code:1": {}
    }
}
```

## Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `version` | string | `latest` | Version to install |

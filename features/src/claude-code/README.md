# claude-code

Installs [Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview) CLI via the official installer.

## Usage

```json
"features": {
    "ghcr.io/shokkunrf/devcontainer-features/claude-code": {}
}
```

## Requirements

- `curl` or `wget` must be available in the container
- `bash` must be available in the container

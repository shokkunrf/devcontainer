# Prettier

Installs [prettier](https://www.npmjs.com/package/prettier) code formatter.

## Usage

```json
{
    "features": {
        "ghcr.io/shokkunrf/devcontainer-features/prettier:1": {}
    }
}
```

## Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `version` | string | `latest` | Version to install |
